# G2.2F.3 — Typography & HUD Proportions

F6 → Resource Bars → HUD style. Four selectable profiles: A Classic RPG (Cinzel 600, 32/24/18/10 px), B Modern Gothic (Roboto Condensed 600, 34/28/16/8 px, default), C Minimal (Inter 500, 26/26/26/8 px, right-aligned), and previous G2.2F.2 (30/26/24/16 px). Height order: Health/Mana/Barrier/EXP. Values use a dark outline, fit to the available height/width, and group thousands in new profiles. EXP remains text-free to preserve its thin shape. Portrait and bar stack center vertically; badge uses the selected font. Changes apply in place to all resource preview typography, main bar heights and badge, without resetting values, level or tweens. Enemy and stress sample dimensions stay fixed. Fonts copied without modification from google/fonts (ofl/cinzel, ofl/robotocondensed, ofl/inter), each with original SIL OFL license. Godot FontVariation selects weight by integer OpenType tag. Previous text sizing is approximate: the same fit guard and ivory color are used for all profiles. Resource PNGs, feedback animations and gameplay unchanged. Smoke tests exercise all profiles and existing resource behavior. Visual review required.

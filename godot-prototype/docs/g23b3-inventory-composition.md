# G2.3B.3 — Inventory Composition Redesign

Base: b8f5776c8b80836122db6f1d034e2ae1bd2f225d (G2.3B.1). Visual audit screenshots at 1920×1080 supplied by the user showed a rigid permanent stats column, a large empty collection panel, and excessively tall native tooltips.

- Two dominant zones: larger character/equipment composition with core stats and potions below; separate inventory collection on the right.
- Details overlay exposes the original five attributes and ten advanced fixture stats on demand.
- Stash retains 40 positions, 24 occupied mock entries, filter/sort/order, selection and disabled economic actions.
- Valuables and Anchor Runes use smaller surfaces; Shrine guidance sits immediately after the rune rows.
- Inventory tabs use quiet underline states. Existing artwork, item slots, resource bars, navigation and Simple frame are reused.
- Opt-in compact tooltip text layout for bounded fixture copy only; no shared gallery changes to wrapping defaults.
- Smoke checks cover overlay visibility, surface restoration, tooltip minimum bounds and original collection counts.

No browser mechanics, real equipment transactions, new art, or other screen redesigns. All stats remain illustrative. Visual verification and Godot execution still required at 1280×720 and 1920×1080.

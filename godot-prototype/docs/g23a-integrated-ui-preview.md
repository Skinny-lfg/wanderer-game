# G2.3A — Integrated UI preview

F5 runs the experimental game shell with the approved kit rather than just the component gallery (F6 remains unchanged). Shared pack loader and bundled Inter/Cinzel typography. Five permanent painted navigation tabs, painted contextual buttons, Standard and Simple PNG-based frames. Camp has character art and resource HUD; Inventory has eight equipped slots plus 48 bag slots and hover tooltips; Combat retains four selectable enemies with compact health bars and the Minimal player HUD (26 px resources, EXP 8 px at 98% width). City, Shrine, Expedition, Codex and Talents receive a first-pass framing treatment; talent graph and rune systems remain illustrative placeholders. No gameplay port, persistence, item management, damage or balance changes. Fixed 1280x720 logical layout remains the first review target. Existing screen capture and smoke tests extended to check shared assets, inventory tooltip and combat HUD. Visual review still needed, especially spacing, typography and art composition. No changes outside godot-prototype.

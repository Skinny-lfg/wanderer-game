# G2.4B.5A — UI Actions & Controls

14 owner-approved designs: confirm, cancel, swap, discard, inspect, lock, unlock, add, remove, upgrade, advance, options, info, adjustments. Each has a framed and isolated PNG. A separate thin frame is included. Source: approved thin-frame concept sheet, extracted from raster crops and resampled to 256 px; not native 256 px artwork. All PNGs are RGBA. Isolated variants use foreground masks and can retain small traces of the original painted edge. Use the framed variant when exact painted appearance is preferred. No text is baked into icons.

Preview at 96, 32 and 24 px outside Godot; use aspect-preserving fit, no nine-slice on symbols. Framed versions are complete icons, not overlays; frame_thin.png is an optional transparent ring. General-purpose controls are optional and do not imply new gameplay features. Existing UI kit, scenes and mechanics remain unchanged. No runtime testing in Godot.

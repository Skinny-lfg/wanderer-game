# Combat VFX pack

Source: user-provided Wanderer_Equipment_and_Combat_VFX_2026_10_15_v2.zip.

Eight original 512×512 transparent PNG images; these are single frames animated with CSS, not sprite sheets. `pack-manifest.json` preserves the original archive metadata (its paths refer to the source ZIP). Equipment PNGs from the same pack are installed in `assets/equipment/` and listed in that directory’s manifest.

Runtime mapping is COMBAT_VFX in index.html. Effects are cosmetic and do not determine damage, affinity or attack cadence.

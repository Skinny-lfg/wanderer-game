## Actual native formulas and source map
- combat/v012-gear-stats.js totalStats: base attributes 5; AP round(4+1.8 STR+0.4 AGI+flat ATK), HP round(55+12 END+flat HP), DEF round(1+0.8 END+flat DEF). Caster SP round(3+1.9 INT+flat SP), mana round(20+7 INT+flat Mana), regen round(1+.15 INT,1 decimal); physical Arcane/Decay enable Mana/SP; Aegis/Orb enable SP without Mana. Full Cloth +40% Mana/SP only if Mana active, mana-affix regen amplified by cloth fraction. Gear/Rune/Talent/boon ordering and caps preserved.
- attackSpeed: 2*(AGI-5 positive)/(100+positive AGI) + .035 speed + caster .65*positive INT/(150+positive INT); divide by weapon interval, 4.2 cap. Native attack clock preserves fractional progress on haste changes.
- Crit: base 9%, diminishing Charisma, gear +8pp cap, global 100%; standard direct multiplier 1.5+critDamage; perfect 1.75+critDamage. Native spell-critical path independently applies same standard multiplier. Evasion rating diminishing, cap 45%, physical-only, Sword parry before evasion. Shield base block based on END and tier, Mace +7pp, gear cap 48 then final 65%, shield reduction Mace 67%, Sword 62%, other 58%, shieldless guard 35%.
- combat/v012-combat-runtime.js weaponAttack: AP factors Sword1.12/Mace1.4/Bow1.08/Daggers.8/2H1.7 minus rounded enemy defense, min1; funded Wand1.05/Staff1.32 SP before other modifiers; no-Mana fallback .55 AP minus defense; Crit, status hooks, direct factors, barrier, HP, post-hit effects. Incoming base max(ceil(.24*enemy ATK),round(ATK*(1-min(.75,DEF/(DEF+1.35*ATK))))); parry -> dodge -> mitigations -> block -> barrier -> HP. Full incoming hit integration, zero-damage block and actual guard caps are follow-up coverage, not certified by scalar fixture.
- setHeal: positive raw * healingPower (except reserve release) * wound .6 * boss and condition factors, clamp max HP, record actual; Barrier shared uncapped pool, raw*(1+wardBonus+barrierPower), encounter reset. Orb ward HP .02 + SP .05, 6s; Tome every 3 paid actions 3/5 MP with 6s; Charm .015/.02 HP on damaging main hit with 8s. Proc-specific tests in existing regressions and B3.
- Native Mana paid vs fallback, reduction cap .25 and floor 1, costs depend on attunement and boons, regen every .11s; exact boundary and capped restoration. Do not equate paid-action telemetry with all spell effects.
- Bleed application rounds raw then snapshots DoT Power; four-second clock, accelerated primary .75s, refresh and reserves distinct. Rot raw .04*(weapon nominal AP/SP damage+SP); paid/ability stacks persistent, sum of stack damage; cap6 replacement, snapshot DoT Power; burst rules separate. ## Findings requiring design/source confirmation (not a balance change)
1. Offhand dagger native runtime permits a half-damage strike every second main-hand attack for any compatible one-handed weapon, including Sword; simulator gearScore comment says Sword+Dagger has no independent second strike. The comment conflicts with executable code. New deterministic test verifies actual cadence; do not change either rule until canonical intent confirmed.
2. Rot paid stacks persistent and additive (not exponential doubling), burst repays fixed 6 ticks. Confirm latest canonical design before calling defect. Test snapshot/cap/persistence, not every talent.
3. Full Cloth +SP gated by active Mana, so Aegis-only physical SP does not get Cloth multiplier; verify intended identity. EvasionChance hardcodes .45 despite EVASION_CAP parameter. These are review points, not established bugs.
4. Incoming zero-damage block code max(1,round(raw*reduction)) could exceed raw=0 before Barrier subtraction, potential edge case; confirm reachable native scenario before change.

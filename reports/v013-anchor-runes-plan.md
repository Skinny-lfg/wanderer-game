# Anchor Runes v1
Replace the old three-choice Boss reward and first-slot signature mechanics with one guaranteed direct Rune Bag item for every final Boss victory, including repeat Expedition clears. No auto-equip. Existing 3 Shrine slots, one per family, no mutation during active Expedition. Rune Bag is a separate Inventory subsection, not ordinary equipment Stash capacity. Capacity 300, start requires one free slot so victory loot is guaranteed. 23 families, single fixed stat, same rarities; fixed rarity factors 1/1.5/2.25/3.25/4, existing gear categories 1/1.15/1.30/1.45/1.60 at E1/5/15/35/70. Drop odds 40/30/20/8.5/1.5%, same across tiers; matching Boss affinity weighted 3x per family. No unlimited percentage growth. Existing old family IDs retained as fixed Common if no rarity; old pending choice supported only to settle existing save, not new rewards. Old Wisdom/Warding/Swiftness signature procs removed. DoT applies periodic damage; crit damage adds to critical multiplier; Barrier applies to Orb, Aegis and Rotguard via existing shared Barrier Power. Mana runes do not unlock Mana on non-mana builds. No new images; reuse existing eight Rune icons as placeholders. No new balance changes or deploy. Regression follow-up includes second-suite stale node count and new Fire costs.
